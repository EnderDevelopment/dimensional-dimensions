# Dimensional Dimensions

Dimensional Dimensions is a Minecraft mod for Forge 1.21.1 that adds four unique dimensions: Dune, Living World, Forgotten World, and World of Deception. Each dimension features custom biomes, blocks, mobs, and mechanics. The Dune dimension is a sandy desert with aggressive Sandworms, the Living World is an organic biome with flesh and bone blocks, the Forgotten World is a decaying, foggy dimension with ghostly mobs, and the World of Deception is filled with mimic mobs that disguise themselves as blocks.

## Install

1. Download the mod file (dimension_mod-1.0.jar) from the releases section.
2. Place the mod file in the mods folder of your Minecraft instance.
3. Launch Minecraft with the Forge 1.21.1 profile.

## Use

1. Use a portal block to travel between dimensions.
2. Explore the unique biomes and interact with custom mobs and blocks.
3. Configure the mod settings in the dimension_mod-common.toml file to enable or disable dimensions.
